# 스마트 딜리버리

## 어떤 기능인가요

스마트 딜리버리는 기존 묶음퀵을 사용자에게 더 이해하기 쉬운 이름으로 바꾼
기능입니다. 보내는 사람 1~5명의 픽업지에서 물품을 모아 받는 사람 2~5명에게
보내는 여러 배송을 하나의 경유 주문으로 접수합니다. 받는 사람마다 어떤 보내는
사람의 물품인지 연결합니다.

묶음퀵 또는 묶음배송이라고 물어봐도 같은 기능을 뜻합니다. 목적지는 받는 사람
기준으로 2곳부터 5곳까지 입력할 수 있고, 보내는 사람 픽업지는 1곳부터 5곳까지
입력할 수 있습니다.

현재 Sandbox에서는 한 사용자가 여러 사람의 배송 정보를 모아 접수하는 방식입니다.
서로 모르는 사용자의 주문을 백그라운드에서 자동 매칭하거나 실제 기사에게 배차하는
운영 기능은 아직 제공하지 않습니다.

## 자동 전환 방식

별도의 서비스 모드를 먼저 고르지 않습니다. 기본 퀵 접수 폼에서 보내는 사람이나
받는 사람을 `+` 버튼으로 추가하면 스마트 딜리버리로 자동 전환되고, 추가한 사람을
모두 삭제하면 일반 퀵으로 돌아갑니다.

## 어느 지역에서 이용할 수 있나요

MOVB 화면은 도시를 서울이나 수도권으로 제한하지 않습니다. 카카오 주소 검색과
퀵 배송 API가 처리할 수 있는 국내 주소라면 대전 등 다른 지역도 입력할 수
있습니다. 실제 서비스 가능 여부와 요금은 입력한 주소로 Sandbox 견적을 조회한
결과를 기준으로 안내합니다.

## 견적은 어떻게 계산하나요

MOVB는 모든 주소를 서버에서 다시 좌표로 확인합니다. 연결된 보내는 사람의
픽업지에서 각 받는 사람에게 각각 보냈을 때의 가격을 합산하고, 모든 픽업을 마친
뒤 배송지를 경유하는 하나의 묶음 견적을 조회합니다. 화면에는 개별 배송 합계,
묶음 가격, 예상 절약 금액, 픽업 순서와 배송 순서를 함께 보여줍니다.

묶음 가격이 항상 더 저렴하다고 미리 단정하지 않습니다. 주소와 차량 조건을 반영한
Sandbox 견적 응답으로 실제 비교 결과를 안내합니다.

## 접수할 때 무엇이 필요한가요

- 보내는 사람별 픽업 주소·이름·전화번호
- 받는 사람별 배송 주소·이름·전화번호
- 각 받는 사람에게 연결할 보내는 사람
- 물품명, 크기, 수량과 선택적인 물품가액
- 대형 물품일 때 사용할 배송 차량
- 추천 경로와 최종 견적을 확인했다는 명시적인 동의

묶음퀵 주문에는 수령인 연락처가 필요합니다. 카카오 주문의 목적지와 경유지에는
수령인 이름과 전화번호가 함께 들어가며, MOVB는 주문 직전 서버에서 이 값들이
빠졌는지 다시 검증합니다.

## 접수 이후

접수된 스마트 딜리버리는 하나의 주문번호로 저장됩니다. 이용 내역에서 전체 주문 상태를
조회하거나 카카오 상태를 동기화하고, 취소 가능한 상태라면 주문을 취소할 수 있습니다.
동일한 접수 키가 반복되어도 같은 주문이 두 번 생성되지 않도록 보호합니다.
