# 묶음퀵

## 어떤 기능인가요

묶음퀵은 한 사용자가 같은 출발지에서 서로 다른 목적지 2~5곳으로 물품을 보낼 때
여러 주문을 하나의 경유 배송으로 접수하는 기능입니다. 서로 다른 사람의 주문을
나중에 매칭하는 합승이 아니라, 한 발송자가 처음부터 여러 목적지를 입력합니다.

## 견적은 어떻게 계산하나요

MOVB는 모든 주소를 서버에서 다시 좌표로 확인합니다. 출발지에서 각 목적지까지
각각 보냈을 때의 가격을 합산하고, 추천 순서대로 모든 목적지를 경유하는 하나의
묶음 견적을 조회합니다. 화면에는 개별 배송 합계, 묶음 가격, 예상 절약 금액과
추천 배송 순서를 함께 보여줍니다.

묶음 가격이 항상 더 저렴하다고 미리 단정하지 않습니다. 주소와 차량 조건을 반영한
Sandbox 견적 응답으로 실제 비교 결과를 안내합니다.

## 접수할 때 무엇이 필요한가요

- 출발지 주소와 보내는 사람의 이름·전화번호
- 목적지별 주소와 받는 사람의 이름·전화번호
- 물품명, 크기, 수량과 선택적인 물품가액
- 대형 물품일 때 사용할 배송 차량
- 추천 경로와 최종 견적을 확인했다는 명시적인 동의

## 접수 이후

접수된 묶음퀵은 하나의 주문번호로 저장됩니다. 이용 내역에서 전체 주문 상태를
조회하거나 카카오 상태를 동기화하고, 취소 가능한 상태라면 주문을 취소할 수 있습니다.
동일한 접수 키가 반복되어도 같은 주문이 두 번 생성되지 않도록 보호합니다.
